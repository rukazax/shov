# Аудиоверсия «Шова» — как это собрано

Озвучка в духе записей 1С-Паблишинг: один чтец-рассказчик, отдельные голоса на персонажей, музыкальная подложка с дакингом, звуковые эффекты на сценарные границы и системные строки. Ничего не покупается и не скачивается — голоса синтезируются, музыка и эффекты генерируются кодом.

## Что чем сделано

| Слой | Инструмент | Файл |
|---|---|---|
| Голоса | нейронный синтез `edge-tts`, 5 тембров | `render.py` |
| Музыка (4 подложки) | синтез numpy: синусы, шум, огибающие | `gen_beds.py` |
| Эффекты (6) | синтез numpy: колокол, статика, удар, сквозняк, скрип, щелчок | `gen_beds.py` |
| Роботизация системных строк | кольцевая модуляция + эхо | `render.py` |
| Сведение, дакинг, лимитер | numpy | `render.py` |
| Нормализация громкости | ffmpeg `loudnorm` -16 LUFS / -1.5 dBTP | `render.py` |
| Кодек | mp3 128 кбит/с, моно, 44,1 кГц | `render.py` |

## Голоса

| Роль | Голос | Настройки |
|---|---|---|
| Рассказчик и Семён (первое лицо) | `ru-RU-DmitryNeural` | темп −4 %, тон −2 Гц |
| Диалоги: мужчины | `en-US-BrianMultilingualNeural` | темп +2 %, тон −4 Гц |
| Диалоги: второй мужской (Семён-2, Сшивка) | `en-AU-WilliamMultilingualNeural` | темп +4 % |
| Диалоги: женщины | `ru-RU-SvetlanaNeural` | темп +2 % |
| Системные строки Согласования | `ru-RU-DmitryNeural` + робот-эффект | темп −12 % |

Мультиязычные голоса читают по-русски без потери темпа: проверено на длительности фразы — 6,0–6,8 с против 6,8 с у русского голоса.

## Подложки

| Файл | Для чего | Что внутри |
|---|---|---|
| `beds/calm.wav` | бытовые и разговорные сцены | пад на малой терции, дыхание LFO, редкий колокольчик |
| `beds/tense.wav` | Стык, бумаги, угрозы | гул 55 Гц, сердцебиение 68 уд/мин, диссонирующая секунда |
| `beds/action.wav` | побег, погоня, провал | пульс 132 BPM, шумовые тарелки, подъём |
| `beds/seam.wav` | Шов, протечка, чужая геометрия | гул 41 Гц с дрожью, шипение |

Подложка выбирается по тексту главы: считаются слова-маркеры («бег», «погоня» → action; «допуск», «ведомость» → tense; «шов», «край» → seam; иначе calm). Дальше — дакинг: огибающая голоса опускает музыку до −22 дБ на речи и поднимает в паузах.

## Порядок сборки

```bash
cd audio
python3 gen_beds.py                 # подложки и эффекты (2 с)
python3 render.py ../BOOK01/ch00_vvedenie.md
python3 render.py ../BOOK01/ch01.md
# ... и так по главам
```

Кэш синтеза — `audio/cache/`, повторный рендер главы идёт 20–25 секунд: озвучка берётся из кэша, пересобирается только микс.

## Цифры

- Введение (8,1 тыс. знаков) — 11,3 минуты, 10,8 МБ.
- Темп чтения: ~720 знаков в минуту (медленнее обычного аудиокнижного, это осознанно: так держится пауза «атамановского» такта).
- Итоговый том 600 тыс. знаков — около 14 часов звучания.
