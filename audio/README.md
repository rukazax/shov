# Аудиоверсия «Шова» — как это собрано

Озвучка в духе записей 1С-Паблишинг: чтец-рассказчик, отдельные голоса на персонажей, музыкальная подложка с дакингом, звуковые эффекты на сценарные границы и системные строки. Ничего не покупается и не скачивается — голоса синтезируются, музыка и эффекты генерируются кодом.

## Что чем сделано

| Слой | Инструмент | Файл |
|---|---|---|
| Голоса | нейронный синтез `edge-tts`, 17 ролей | `render.py` |
| Музыка (4 подложки) | синтез numpy: синусы, шум, огибающие | `gen_beds.py` |
| Эффекты (6) | синтез numpy: колокол, статика, удар, сквозняк, скрип, щелчок | `gen_beds.py` |
| Роботизация системных строк | кольцевая модуляция + эхо | `render.py` |
| Сведение, дакинг, лимитер | numpy | `render.py` |
| Нормализация громкости | ffmpeg `loudnorm`, −16 LUFS | `render.py` |
| Проверка разметки ролей | правила по именам и роду глаголов | `cast_audit.py` |
| Кодек | mp3 96 кбит/с, моно, 44,1 кГц | `render.py` |

## Разметка ролей: `cast/`

Кто говорит каждую реплику — отдельный файл на главу, `cast/chNN.cast.txt`:

```
74	dialogue	hero	А до меня сюда кто-нибудь лазил? – спросил я у вахтёрши.
111	dialogue	babka	Сеня, – вышла она на балкон, – звони Вите.
```

Колонки: номер блока, тип (`dialogue`/`narration`/`system`), роль, текст. Правится **только роль**, остальное — для контекста. Строки на `#` игнорируются.

| Действие | Команда |
|---|---|
| выгрузить разметку из эвристики | `python3 render.py ../BOOK01/ch01.md --dump-cast` |
| применить патч (`номер<TAB>роль`) | `python3 cast_audit.py cast/ch01.cast.txt --apply patch.txt` |
| проверить все главы | `python3 cast_audit.py` |
| посмотреть разбор без синтеза | `python3 render.py ../BOOK01/ch01.md --only-text` |

Если файл `cast/chNN.cast.txt` есть — рендер берёт роли из него и печатает, что исправил. Нет файла — работает прежнее угадывание по ремаркам. Роль вне списка не применяется (опечатка не глушит голос молча).

Правка роли дешёвая: `cache_key` считается от голоса, темпа, тона, громкости и текста, поэтому пересинтезируется ровно тот блок, у которого сменилась роль, а не вся глава.

`cast_audit.py` находит только доказуемое: имя при глаголе речи против роли, род глагола (`сказал` у женской роли), «сказал он» в реплике героя-рассказчика (о себе он сказал бы «сказал я») и «сказал я» у чужой роли. Просто упомянутое имя не считается — «Михалыч же её поставил» говорит Витя, а не Михалыч.

Угадывание по ремаркам ошибается примерно на 40 % реплик: на главах 1–5, размеченных чтением, эвристика разошлась с разметкой в 195 блоках из 488. Поэтому `cast/*.cast.txt` — обязательный этап, а не украшение; автогенерация (`--dump-cast`) годится только как черновик.

Съезд двух собеседников в сплошном диалоге без ремарок механически не виден — такие места надо читать.

## Голоса

Роли в `VOICES` (`render.py`). Тембры подобраны под персонажа, поверх них ложится просодия от знаков и ремарок.

| Роль | Кто это | Голос |
|---|---|---|
| `narrator` | повествование от третьего лица | Dmitry, −2 % / −2 Гц |
| `hero` | Сеня, первое лицо | Andrew, +1 % / +1 Гц |
| `babka` | бабушка Сени, Нина Петровна | Ava, −11 % / −7 Гц |
| `agrafena` | Аграфена Тихоновна, старуха автолавки | Svetlana, −14 % / −10 Гц |
| `vitya` | Витя | Remy, +5 % / +7 Гц |
| `bocman` | Боцман | William, −10 % / −14 Гц |
| `mihalych` | Михалыч, начальник участка; **тем же голосом Пётр Ильич** (они никогда не в одной сцене) | Dmitry, −7 % / −9 Гц |
| `muhin` | Мухин, Аркадий Львович | Giuseppe, −4 % / −8 Гц |
| `grisha` | Гриша, кладовщик | Remy, −1 % / −2 Гц |
| `leytenant` | лейтенант | Andrew, +3 % / +5 Гц |
| `tehnik` | техник и любой безымянный мужчина | Remy, +2 % / +2 Гц |
| `ganna` | Ганна Фёдоровна | Svetlana, −7 % / −5 Гц |
| `dasha` | Даша, дочь | Emma, +6 % / +9 Гц |
| `pozharskaya` | Пожарская, Ольга Тимуровна | Emma, −3 % / −4 Гц |
| `lida` | Лида | Ava, +2 % / +3 Гц |
| `female` | любая безымянная женщина, Юля | Ava, −1 % / 0 Гц |
| `system` | системные строки Согласования | Dmitry + робот-эффект |

Голосов меньше, чем людей: безымянные прохожие, вахтёрши, дежурные и курьеры делят `tehnik` / `female`. Это приём, а не недосмотр — но проверять надо, чтобы два таких человека не оказались в одной сцене.

Мультиязычные голоса читают по-русски без потери темпа: проверено на длительности фразы — 6,0–6,8 с против 6,8 с у русского голоса.

Просодия от знака: вопрос — выше и быстрее, `!` — громче, `…` — медленнее, короткая рубленая реплика — суше и ниже, длинный абзац описания — ровнее. Крик и шёпот узнаются по ремарке («заорал», «прошептал», капс).

## Подложки

| Файл | Для чего | Что внутри |
|---|---|---|
| `beds/calm.wav` | бытовые и разговорные сцены | пад на малой терции, дыхание LFO, редкий колокольчик |
| `beds/tense.wav` | Стык, бумаги, угрозы | гул 55 Гц, сердцебиение 68 уд/мин, диссонирующая секунда |
| `beds/action.wav` | побег, погоня, провал | пульс 132 BPM, шумовые тарелки, подъём |
| `beds/seam.wav` | Шов, протечка, чужая геометрия | гул 41 Гц с дрожью, шипение |

Подложка выбирается по тексту главы: считаются слова-маркеры («бег», «погоня» → action; «допуск», «ведомость» → tense; «шов», «край» → seam; иначе calm). Дальше — дакинг: огибающая голоса опускает музыку на речи и поднимает в паузах. Низ подложки срезан на 110 Гц — иначе он гудит в паузах и читается как шум дорожки.

## Порядок сборки

```bash
cd audio
python3 gen_beds.py                 # подложки и эффекты (2 с)
python3 cast_audit.py               # что в разметке вызывает вопросы
python3 render.py ../BOOK01/ch01.md
./render_book.sh 0 33               # или все главы, 4 воркера
python3 check_out.py                # длительность, громкость, тишина
```

Кэш синтеза — `audio/cache/`, повторный рендер главы идёт 20–25 секунд: озвучка берётся из кэша, пересобирается только микс.

## Цифры

- Введение (8,1 тыс. знаков) — 11,3 минуты, 7,7 МБ, −16,4 LUFS, пик −0,8 dBTP.
- Разметка тома: 34 главы, 6840 блоков, из них реплик диалога — около 2300.
- Темп чтения: ~720 знаков в минуту (медленнее обычного аудиокнижного, это осознанно: так держится «атамановский» такт).
- Итоговый том 600 тыс. знаков — около 14 часов звучания.
