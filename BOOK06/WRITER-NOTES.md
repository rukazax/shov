# Том 6 «Чужая родня» — памятка писателю

Читай в этом порядке: `BOOK06/BIBLE.md` (канон), `BOOK06/SPINE.md` (события глав), свой бриф из `BOOK06/BRIEFS/`, и хвост предыдущей главы тома (если файл уже есть на диске).

## Что писать

Одна глава — один файл `BOOK06/chNN.md` (двузначный номер: `ch07.md`). Первая строка файла — заголовок вида `# Глава седьмая. Название` (номер словами, как в брифе). Глава 1 — `# Глава первая. …`.

Нормы (машинный гейт мерит их буквально):
- 17–19 тыс. знаков с пробелами на главу.
- 3–6 сцен, между сценами отдельная строка `* * *`.
- Диалог — 40–60 % строк (в томах 1–4 медиана ~60 %; 30 % — уже сухо, так пишем только «тихие» главы и главы чужого POV).
- Системная строка — примерно одна на 4 тыс. знаков, отдельной строкой, без кавычек, после поступка: `Согласование: 26,8%. Ранг: опора. Допуск: № 11-с/5.`
- Никаких других глав и файлов не трогать. Коммитить нельзя.

## Голос

Первое лицо, добродушная ирония, бытовой здравый смысл. Герой оценивает себя вслух («Сгодится.», «Блин, затупил…», «Неплохо, совсем неплохо»). Длинный абзац-разбор → короткая фраза-удар отдельной строкой («Пусто.», «Обошлось.», «Мда…»).

Связки: «вот только», «хотя», «причём», «похоже», «между тем», «кстати», «даже», «просто», «вот», «О как…». Сравнения — через «словно», бытовые и телесные.

Диалог — только короткое тире `– `. Ремарка-действие отдельным абзацем. Кавычки «ёлочки», многоточие `…`. Длинного тире `—` в тексте быть не должно вовсе. Брань не печатать: «Ёшкин кот!», «Ёклмн…», «какого чёрта», «блин». Канцелярит — только в устах службы и с иронией.

Земной якорь в каждой главе: пропускной режим, наряд-задание, опись, платёжка, очередь в кассу, школьный чат, объявление на проходной.

Клиффхэнгер — в каждой второй главе.

## Атрибуция (обязательно)

Каждая реплика без имени в тексте обязана иметь ремарку с глаголом речи в правильном роде и с именем: `– Текст, – сказала Пожарская.` / `– Текст, – сказал я.`

Конструкция «– сказал он» для рассказчика запрещена: «он» в этом томе — и Семён, и Семён-2. Для второго — всегда с признаком: «сказал второй», «сказал устой», «сказал сторож с той стороны».

## Канон

Новых объектов канона не вводить: всё нужное уже в библии. Цифры (Согласование по ступеням 31,1 → 33,7 → 35,2 → 37,4 %, две подписи на бланке, два перехода в месяц, двенадцать фамилий, лист сорок седьмой, цена «дом») — только из библии.

Чужой POV (Римма Кузьминых, бюро родства) — только в главах 3, 11, 20, 30: третье лицо, канцелярский голос с иронией в скобках, «системная строка» у неё — строка описи без кавычек.

## Проверка перед сдачей

```
wc -m BOOK06/chNN.md                      # 17–19 тыс.
grep -c '—' BOOK06/chNN.md                # 0
grep -nP '[A-Za-z]' BOOK06/chNN.md        # пусто (латиницы быть не должно)
grep -c '^\* \* \*$' BOOK06/chNN.md       # 2–5 разделителей сцен
```

Если предыдущая глава уже написана — прочитать её последние 30 строк и начать свою с того места, где она кончилась (или с явного «на следующий день»).
