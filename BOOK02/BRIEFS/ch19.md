# Бриф: глава 19. «Обратный ход»

Объём: 17–19 тыс. знаков с пробелами. Сцен 3–6, между ними строка `* * *`.
Первая строка — реплика или действие. Диалог — 30–45 % строк. Системная строка — одна на ~4 тыс. знаков, отдельной строкой, без кавычек, после поступка.
Канон — `BOOK02/BIBLE.md`. Голос и темп — по `BOOK02/ch01.md` и предыдущей главе.
Новых объектов канона не вводить. Больше быта и разговоров, меньше механики.

## Что происходит

Путь назад без карты. Компас оживает: стрелка ищет тонкость. Костя не может идти — несут по очереди, Сомов помогает (впервые). Ковалёва находит в кармане записку Нины: «Папа сказал, идите на юг, там нитка». Встречают «нитку» — тонкую жилу через лес, идут по ней. Семён считает шаги, как учил Гущин.
Земной якорь: шаги, компас, снег.
