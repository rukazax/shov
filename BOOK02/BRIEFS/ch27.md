# Бриф: глава 27. «Тонкое место»

Объём: 17–19 тыс. знаков с пробелами. Сцен 3–6, между ними строка `* * *`.
Первая строка — реплика или действие. Диалог — 30–45 % строк. Системная строка — одна на ~4 тыс. знаков, отдельной строкой, без кавычек, после поступка.
Канон — `BOOK02/BIBLE.md`. Голос и темп — по `BOOK02/ch01.md` и предыдущей главе.
Новых объектов канона не вводить. Больше быта и разговоров, меньше механики.

## Что происходит

Путь по стрелке: дворы, гаражи, стройка, школа, садик. Компас ведёт не к шахте. По дороге — бытовые сцены: очередь в поликлинике, женщина с коляской, мальчик с собакой. Семён понимает: тонкость бывает не только под землёй. Встречает Боцмана, который говорит: «Ты идёшь не туда, куда думаешь».
Земной якорь: дворы, садик, поликлиника.
